## What's this

This mod adds meteorite motif weapons, tools and armor.

## How do I obtain items?

Locate a "Meteorite" underground, destroy the "Stardust Reverie" found inside, and obtain a "Smithing Template." Next, mine the "Meteorium Ore"—also generated underground—to acquire "Meteorium Dust." Combine this dust with a "Copper Ingot" to create a "Meteorium Ingot." Finally, by combining any diamond tool or armor with the Smithing Template and the Meteorium Ingot, you can craft a Meteorium tool & armor.

Meteorium tools are extraordinarily powerful.
